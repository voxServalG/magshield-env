# 常见问题

**为什么拒绝非 SI 单位？**

v0.1 只消费规范 SI 源文件。把非 SI 导出通过确定性、经过评审的预处理步骤转换，保留原始文件和转换记录，再导入转换后的文件。改列名不是单位转换。

**输出目录已经存在，能覆盖吗？**

不能。导出到新的空目录。便携包恰好包含六个文件，任何多余或改动的成员都会让校验失败。

**动态几何环境能省略导体几何吗？**

不能。动态包必须包含完整路径、贡献和框架；不存在固定矩阵回退或最近位姿插值。

**这个项目会训练策略吗？**

不会。它只构建和加载 Gymnasium 环境；训练、评估和策略发布都在项目边界之外。

**错误输出怎么读？**

命令在 stdout 输出一个 JSON 信封，失败时 `error` 里有 `type`、`subtype`、`message` 和 `hint`。先读 `ok` 字段，再按 `hint` 修复源头。

**文档和 `--help` 不一致时以谁为准？**

以 `--help` 为准。本站故意不复制命令参数；如果发现本站引用了不存在的 flag，请提 issue 或 PR 修正。

**我想给文档提 PR，需要满足什么？**

中文是事实源，英文是翻译；命令细节进 `--help`，设计思想进 `docs/`，工作流进 `skills/`。CI 会以警告即失败、linkcheck 和示例可复现作为门禁。
