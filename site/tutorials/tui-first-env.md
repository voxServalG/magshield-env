# 教程：用 TUI 构建第一个环境

本教程带你走完从物理定义到可加载环境包的完整流程。开始前先运行 `magshield-env tui --help` 确认当前界面参数；界面本身是交互式的，命令参数以 `--help` 为准。

## 打开向导

```bash
uv run magshield-env tui
```

如果运行环境没有鼠标支持，可以按 `--help` 中的说明关闭鼠标输入。向导共五个页面，每一页完成并校验通过后才能进入下一页。

## 第一步：采样区域

选择“生成”或“导入”：

- **生成**：声明一个笛卡尔盒、圆柱、球体或球面点集，给出边界、间距（或点数）和中心。
- **导入**：选择 CSV、HDF5 或 VTK 族点集文件，并显式声明坐标框架。

进入下一步前，检查点数量、空间范围、点顺序和权重是否就是你想要的评估网格。框架不是可选项——没有框架，后面的响应矩阵和外部场都没有意义。

## 第二步：正向模型

三选一，且只能选一个：

- **固定响应矩阵**：一个 `[N, 3, M]` 的响应张量，点和通道顺序已绑定。
- **有限元逐通道场**：每个通道一个三分量 CSV（或 HDF5/VTK 变体），全部作用在同一权威点集上。
- **导体几何**：CSV/VTP 路径加通道几何 YAML，运行期按位姿实时计算 Biot-Savart 响应。

如果选动态几何，向导会要求路径框架和位姿源/目标框架；这三个框架必须构成正确的变换链。

## 第三步：硬件

对每个通道声明电流下限、电流上限、正向爬升率、电阻和电压上限，再声明控制器步长。通道标识必须唯一，并且顺序与响应矩阵的通道列完全一致。

## 第四步：场景

静态场景可以带一个外部场和（可选的）完整位姿；位姿必须是平移加四元数成对出现。轨迹场景则绑定一个 HDF5 文件，其中所有随时间变化的数组共享相同的帧数。动态几何环境里，每个运行时帧都必须有位姿。

## 第五步：环境行为

选择全场观测还是线性基投影、是否把位姿放进观测、非法动作采用“投影并报告”还是“终止回合”，并声明奖励各项的尺度和权重。这些都是物理声明，不是事后再调的隐藏参数。

## 校验页与导出

最后一页列出点数和通道数、响应形状与秩、响应内存估算、动态计算成本，以及所有阻塞问题。**只有零阻塞问题时才允许导出。** 选择一个全新的空目录，向导会原子地写出环境包；它不会覆盖已有目录。

导出后，运行包校验器和检查器，然后加载一次并执行一个合法 step，再交给下游强化学习代码：

```bash
uv run magshield-env validate path/to/environment
uv run magshield-env inspect path/to/environment --pretty
```

```python
import numpy as np

from magshield_env import make_env

env = make_env("path/to/environment")
obs, info = env.reset(seed=0)
obs, reward, terminated, truncated, info = env.step(
    np.zeros(env.action_space.shape, dtype=np.float64)
)
```

任何校验失败都按错误信息里的提示修复源文件，再重新校验；不要通过放宽容差、重排数据或切换物理模式来“获得”一个包。
