# 概念：单位、形状与规范格式

所有数值物理数组都是 float64，单位是固定的 SI 集合：长度米（`m`）、磁场特斯拉（`T`）、电流安培（`A`）、时间秒（`s`）、电阻欧姆（`ohm`）、电压伏特（`V`）；每安培响应是 `T/A`。导入的非 SI 数据必须在进入规范格式之前完成转换，转换过程和来源身份进入构建溯源。

形状也是契约：

- 点集：`[N, 3]`，`N` 是点数量。
- 响应矩阵：`[N, 3, M]`，`M` 是通道数量；第二维是三个矢量分量。
- 通道字段：`[N, 3]`。

形状相同永远不等于语义相同：坐标框架、通道顺序、点顺序都是独立的身份维度。`manifest.json` 会把点顺序、通道顺序、坐标框架、数组形状和内容哈希全部绑定。

交换格式（CSV、HDF5、VTK/VTP、YAML）的精确布局见[参考：格式契约](../reference/format-contracts)，JSON Schema 投影见[参考：JSON Schema](../reference/schemas)。
